Promotion mechanism
-------------------
Lakebase branches are copy-on-write snapshots with no merge operation, so
promotion is re-application of the validated migration to the root branch:

    python3 lakebase/apply_migrations.py production

Every statement is IF NOT EXISTS or otherwise idempotent, verified by re-running
the whole migration set against main with no error and no duplicate objects.
