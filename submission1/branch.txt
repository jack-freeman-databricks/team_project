Promotion back to main
----------------------
Verified isolation first: main did NOT contain work_order_note before promotion
and DID after. See agent_change/promotion_evidence.txt.

Lakebase branches are copy-on-write and have no merge operation, so promotion
means re-applying the validated migration to the root branch. Every migration is
written IF NOT EXISTS / idempotent, which is what makes that safe and repeatable
(lakebase/apply_migrations.py re-runs the whole set against any branch).
